# Likelihood-Ratio Tests for the Makeham Term

Silvio C. Patricio

Interdisciplinary Center on Population Dynamics, University of Southern Denmark

**Preprint:** *[Link to be added]*

Code and reproducibility materials for the manuscript *Does a mortality schedule need a Makeham term? Calibrating the likelihood-ratio test*.

The simulations study how to test for an age-independent Makeham component in mortality models. They illustrate finite-sample calibration, the power to detect a positive Makeham term, and the change in the test's reference distribution when a gamma-frailty variance is estimated at a true value of zero. All death counts are simulated; no external data or data-access credentials are required.

```r

```

## Run the analysis

Run the following commands from the repository root:

```bash
MAKEHAM_MODE=full MAKEHAM_WORKERS=8 Rscript 02_run_simulations.R
Rscript 03_make_tables.R
Rscript 04_make_figures.R
```

Alternatively, in RStudio, set the working directory to the repository root and run:

```r
Sys.setenv(MAKEHAM_MODE = "full", MAKEHAM_WORKERS = "8")
source("02_run_simulations.R")
source("03_make_tables.R")
source("04_make_figures.R")
```

Run scripts 02–04 in numerical order. They load `01_functions.R` automatically. The table and figure scripts read saved results and do not repeat the simulations.

Full mode uses the manuscript design:

- Single-year ages **30–90 inclusive**, with Gompertz parameters lambda = 0.00002 and beta = 0.10.
- Exposures proportional to Gompertz survivorship, normalized to sum to one and multiplied by total exposure n.
- Total exposures of **10,000, 100,000, 1,000,000 and 10,000,000 person-years**.
- **10,000 independent datasets per scenario**, at each combination of total exposure and standardized Makeham shift.
- A test level of 0.05 and a target power of 0.80.
- **100,000 separate Gaussian draws** to approximate the joint-boundary limiting distribution.

The standardized shifts run from 0 to 3 in steps of 0.25, with an additional point at the local 80% power threshold. The master seed is 1. Edit the settings near the top of `02_run_simulations.R` to run a different design.

For a short test run:

```bash
MAKEHAM_MODE=smoke MAKEHAM_WORKERS=2 Rscript 02_run_simulations.R
Rscript 03_make_tables.R
Rscript 04_make_figures.R
```

Smoke mode uses 20 datasets per scenario and 5,000 Gaussian draws. Pilot mode (`MAKEHAM_MODE=pilot`) uses 200 datasets per scenario and 100,000 Gaussian draws. Neither replaces the full manuscript run.

Only one run is active in `results/`. Move or rename that folder after a run finishes before switching modes or changing the design. With unchanged settings, source files and R version, rerunning script 02 reuses completed checkpoints and resumes unfinished work.

Parallel execution uses separate R sessions and works on macOS, including in RStudio. Set `MAKEHAM_WORKERS` to the desired number of workers; eight is a starting configuration for an Apple M4 Max with 36 GB of memory. Each batch has its own seed, so changing the worker count does not change the simulated datasets.

## Main outputs

- `results/replicate_results.csv` and `.rds`: one row per simulated dataset, with likelihood-ratio statistics, test decisions and fit statuses.
- `results/checkpoints/`: simulated death counts, exposures, parameter estimates, fitted rates and optimizer diagnostics.
- `results/tables/table1_calibration.tex`: the finite-sample calibration table for the manuscript.
- `results/tables/power_curves.csv` and `detection_threshold.csv`: empirical power across the alternatives and at the approximate 80% power threshold.
- `results/tables/joint_boundary_summary.csv`: finite-sample results when the true Makeham constant and frailty variance are both zero.
- `results/tables/numbers_for_manuscript.csv`: efficient information, score correlation, critical values and the standardized detection threshold.
- `results/figures/figure1_local_power.pdf`: empirical power and local-power approximations.
- `results/figures/figure2_joint_boundary.pdf`: finite-sample and limiting upper-tail probabilities at zero true frailty variance.
- `results/manifest.rds` and `session.txt`: settings, seeds, design information and the computing environment.

Additional files in `results/tables/` report Monte Carlo uncertainty, failure counts, fitted parameters and sensitivity to the numerical-zero tolerance.

## Simulation note

The Makeham-only comparison fits Gompertz against Gompertz–Makeham. The joint-boundary comparison fits gamma-Gompertz against gamma-Gompertz–Makeham, estimating frailty under both hypotheses even though its generating value is zero.

The joint-boundary critical value uses the known generating information matrix. This experiment illustrates the effect of the reference distribution; it does not evaluate a calibration selected from the fitted frailty variance.

Failed comparisons remain missing and are reported separately. Rejection probabilities use successful fits, with supporting bounds that account for failures. Monte Carlo intervals describe simulation uncertainty, and the local detection threshold is an asymptotic approximation rather than a guarantee of 80% finite-sample power.
